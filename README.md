# 🔍 GitView 2.0 — GitHub Developer Analytics Platform

> An interactive, client-side GitHub analytics dashboard built with modern HTML5, CSS3, and Vanilla JavaScript. Analyze GitHub profiles, explore repositories, visualize language distributions, compare developers side-by-side, and export performance reports — all without a backend.

🌐 **Live Demo:** [https://rushikesh09-cod.github.io/gitview/](https://rushikesh09-cod.github.io/gitview/)

---

## ✨ Features

- 👤 **Comprehensive Profile Analytics** — View bio, location, company, website, Twitter/X handle, hireable status, and account creation timeline.
- 📊 **Language Distribution Visualizer** — Interactive language breakdown charts calculated across public repositories.
- 📁 **Repository Explorer** — Search and filter repos by language, sort by Stars, Forks, or Last Updated, with pagination and direct GitHub links.
- 👥 **Side-by-Side User Comparison** — Compare two GitHub developers head-to-head across stars, followers, repos, and activity.
- 📈 **Contribution Activity Heatmap** — Visualize yearly contributions and commit patterns.
- ⭐ **Bookmarks & Favorites** — Save favorite developer profiles to local storage for quick one-click access.
- 🕒 **Recent Search History** — Quick dropdown history of recently viewed profiles.
- 🌓 **Dark & Light Mode** — Seamless theme toggle with automatic persistence.
- 📄 **PDF / Report Export** — Download clean printable developer summary cards.
- 🔗 **Direct URL Profile Sharing** — Share exact developer profiles via hash URLs (e.g. `#torvalds`).
- ⚡ **Pure Client-Side Architecture** — Zero external frameworks; powered entirely by native Web APIs, Fetch API, and GitHub REST API v3.

---

## 🛠️ Tech Stack

- **Markup:** HTML5 (Semantic Structure)
- **Styling:** Vanilla CSS3 (Custom Design System, CSS Variables, Glassmorphism, Responsive Grid & Flexbox)
- **Scripting:** Vanilla JavaScript (ES6+, Async/Await, Fetch API, LocalStorage, History API)
- **API:** [GitHub Public REST API](https://docs.github.com/en/rest)
- **Hosting:** GitHub Pages

## 🚀 Quick Start (Local Setup)

1. **Clone the repository:**
   ```bash
   git clone https://github.com/rushikesh09-cod/gitview.git
   cd gitview
   ```

2. **Open in browser:**
   Double-click `index.html` or open it with Live Server in VS Code. No build steps or npm installations required!
